## Aktualizacja

Po zmianie skryptu podbij `@version` w nagłówku i wrzuć na `main`. Tampermonkey sprawdza aktualizacje wg własnego harmonogramu (Ustawienia → Sprawdzaj aktualizacje), a ręcznie: Narzędzia → Sprawdź aktualizacje.
